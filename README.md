# My CV - Website CV Cá Nhân
##  Giới thiệu
Đây là dự án website CV cá nhân được xây dựng bằng HTML và CSS, nhằm giới thiệu thông tin, kỹ năng và kinh nghiệm của bản thân.
##  Công nghệ sử dụng
- HTML5
- CSS3
- Git và GitHub
##  Cấu trúc dự án
text
my-cv/
├── index.html
├── style.css
└── README.md
##  Cách chạy dự án
1. Tải repository về máy.
2. Mở thư mục dự án bằng VS Code.
3. Mở file `index.html` bằng trình duyệt.

##  Tùy chỉnh CV
1. Mở `index.html` bằng VS Code hoặc trình soạn thảo văn bản.
2. Thay tên, chức danh, địa chỉ, email, số điện thoại và liên kết mạng xã hội mẫu bằng thông tin của bạn. Cập nhật cả phần mô tả trang ở thẻ `<meta name="description">` và tiêu đề trong `<title>`.
3. Chỉnh sửa nội dung trong các mục giới thiệu, kỹ năng, học vấn, kinh nghiệm và dự án; có thể thêm hoặc xóa các thẻ `<article>` tương ứng.
4. Thay chữ viết tắt `MA` trong avatar bằng chữ cái tên của bạn. Nếu muốn dùng ảnh thật, thay phần tử `<div class="avatar">` bằng thẻ `<img>` và thêm quy tắc kích thước, bo tròn trong `style.css`.
5. Mở `style.css` để đổi màu sắc, phông chữ hoặc khoảng cách. Các màu chính được khai báo ở đầu tệp trong khối `:root`.
6. Lưu tệp và tải lại trang trong trình duyệt để xem thay đổi. Dùng chức năng in của trình duyệt để lưu CV thành PDF.

Các thông tin trong CV hiện tại đều là nội dung mẫu. Phông chữ Google Fonts chỉ tải được khi có kết nối Internet; nếu không, trang sẽ dùng phông chữ dự phòng của thiết bị.
